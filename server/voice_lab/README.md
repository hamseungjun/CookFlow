# 맥 음성 테스트

`python3 scripts/start_voice_lab.py`로 시작한 뒤 http://localhost:8787 를 연다. 서버는 127.0.0.1에만 바인딩되며 iOS 앱의 공개 터널에 연결하지 않는다. 제공자 API 키는 브라우저에 보내지 않는다. 같은 출처 검사와 페이지 세션 토큰으로 요청을 제한한다.

기본은 마이크 녹음 → gpt-4o-transcribe → 앱과 동일한 OpenAI Decisions 판정. 브라우저 음성 인식은 비교 옵션이다. 입력 장치/음량, 받아쓰기 원문, 판정, 확신도, 지연, 진행 기록을 확인할 수 있다. 녹음 재생과 결과 내려받기를 제공한다. 서버는 녹음 및 결과를 저장하지 않는다. 사용자가 시작한 마이크 녹음은 OpenAI로 전송된다. 중지 또는 다른 탭 전환 시 마이크 트랙을 닫는다.

순두부찌개 7단계는 Swift 핵심 엔진에서 내보낸 기본 레시피다. 전체 안내 미리 준비를 누르면 앱과 같은 AI 음성을 생성한다. 단계 전환 시 준비한 파일을 재생하며 안내 동안 마이크 판정을 멈춘다. 기본 테스트 타이머는 5초이고 체크를 해제하면 원래 조리 시간을 쓴다. 이 페이지는 원인 분리용이며 iOS의 Apple 음성 인식과 동일한 엔진은 아니다.

2026-10-12 검증: 기존 ‘넣었어’ 음성 파일 → ‘넣었어.’ → confirm .99, ‘했어’ 파일 → ‘했어’ → confirm .99. 실제 Chrome 마이크에서 ‘했어’/‘넣었어.’ → confirm .99 → 타이머 시작이 화면에 관측됨. 모든 환경의 인식 정확도를 보장하지 않는다.

공식 API 참고: https://developers.openai.com/api/reference/resources/audio/subresources/transcriptions/methods/create
