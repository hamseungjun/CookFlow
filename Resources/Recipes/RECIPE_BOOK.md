# 승준 개인 레시피북

> **마스터 레시피북**\
> 목적: 인터넷 레시피를 매번 새로 찾는 대신, 실제로 만들어 먹고 수정한
> 승준의 레시피를 장기적으로 축적한다.

## 0. 운영 원칙

1.  모든 레시피는 기본적으로 **1인분 / 2인분**을 모두 표기한다.
2.  재료는 가능하면 **g, ml** 단위로 적고 필요하면 T(큰술), t(작은술)를
    병기한다.
3.  **승준이 직접 알려준 레시피와 비율은 임의로 변경하지 않는다.**
4.  개선이 필요하면 기존 레시피를 보존하고 변경안을 별도로 제안한다.
5.  실제 조리 후 받은 피드백을 다음 버전에 반영한다.
6.  `레시피북 보여줘` → 현재 메뉴 목록을 보여준다.
7.  `OO 레시피 꺼내줘` → 저장된 최신 버전을 보여준다.
8.  `OO 수정해` → 기존 레시피를 기준으로 수정한다.
9.  정확한 양이 검증되지 않은 레시피는 **테스트 중**으로 관리한다.
10. 자취 환경을 고려하여 팬/냄비 1개 중심, 또는 순차 조리를 우선한다.
11. 새로 제안하는 메뉴는 기존 재료·양념과 활용도가 높은 것을 우선한다.
12. `확정`은 승준이 직접 확정했거나 승준이 제공한 레시피에만 사용한다.

### 상태 표기

-   **사용자 레시피**: 승준이 직접 제공한 배합. 임의 변경 금지.
-   **등록 레시피**: 현재 레시피북 기준으로 사용 중인 레시피.
-   **테스트 중**: 아직 승준의 실조리 검증 전. 양과 조리법 수정 가능.
-   **추천 추가**: 레시피북 확장을 위해 새로 제안한 메뉴. 우선 테스트
    중으로 관리.

# 2. 사용자·등록 레시피

## 제육볶음

**상태: 사용자 레시피 --- 기본 배합 임의 변경 금지**

### 기본 배합

> 현재 사용자가 제공한 기준은 목전지 300g 배합이다. 1/2인분 환산은 실제
> 식사량을 확정한 뒤 추가한다.

-   목전지 300g
-   다진 마늘 1T
-   후추
-   양파
-   대파
-   고추장 1T
-   고춧가루 1T
-   굴소스 1T
-   설탕 1T
-   식용유

### 조리

1.  목전지 300g을 기름을 두른 팬에서 먼저 볶는다.
2.  어느 정도 볶아지면 다진 마늘 1T와 후추를 넣는다.
3.  양파와 대파를 넣어 볶는다.
4.  고추장 1T, 고춧가루 1T, 굴소스 1T, 설탕 1T를 넣고 충분히 볶는다.

### 메모

-   승준이 직접 사용하는 배합.
-   설탕 1T 포함 현재 비율을 유지한다.
-   1인분/2인분 정확한 고기량은 추후 실사용 기준으로 확정한다.

## 계란장

**상태: 사용자 레시피 --- 간장물 비율 임의 변경 금지**

### 간장물 기본 배합

-   진간장 60ml
-   설탕 60g
-   물 180g
-   양파 --- 미확정
-   통마늘 --- 미확정
-   대파 --- 미확정

### 조리

1.  간장, 설탕, 물, 양파, 통마늘, 대파를 냄비에 넣는다.
2.  끓인다.
3.  간장물을 완전히 식힌다.
4.  삶은 계란을 넣고 숙성한다.

### 메모

-   계란 개수와 채소 정확량은 아직 미확정.
-   실제 조리 후 1인분/2인분 기준을 확정한다.

## 순두부찌개

**상태: 등록 레시피**

  재료                                 1인분        2인분
  ----------------------------- ------------ ------------
  순두부                          350g (1봉)   700g (2봉)
  애호박                                 70g         140g
  양파                                   50g         100g
  다진 마늘                              10g          20g
  물                                   250ml        500ml
  청정원 멸치·디포리 코인육수            1개          2개
  고춧가루                              1.5T           3T
  진간장                                  1T           2T
  멸치액젓                                1t           2t
  식용유                                  1T           2T
  후추                                적당량       적당량
  계란                              1개 선택     2개 선택
  대파                                  선택         선택

### 조리

1.  냄비에 식용유를 넣고 약불\~중약불로 가열한다.
2.  양파와 다진 마늘을 볶는다.
3.  고춧가루를 넣고 약불에서 20\~30초 볶아 고추기름을 만든다.
4.  진간장을 냄비 가장자리에 넣어 10\~20초 끓여 향을 낸다.
5.  물, 코인육수, 멸치액젓, 애호박을 넣는다.
6.  끓기 시작하면 3\~4분 끓인다.
7.  순두부를 숟가락으로 큼직하게 떠 넣는다.
8.  약 3\~4분 더 끓인다.
9.  후추를 넣고 원하면 계란과 대파를 추가한다.

**핵심:** 고춧가루를 기름에 먼저 볶는다. 순두부 투입 후 많이 젓지
않는다.

## 우삼겹 순두부찌개

**상태: 등록 레시피**

  재료             1인분       2인분
  ----------- ---------- -----------
  순두부            350g        700g
  우삼겹        80\~100g   160\~200g
  애호박             70g        140g
  양파               50g        100g
  다진 마늘          10g         20g
  물               250ml       500ml
  코인육수           1개         2개
  고춧가루          1.5T          3T
  진간장              1T          2T
  멸치액젓            1t          2t
  후추            적당량      적당량
  계란          1개 선택    2개 선택
  대파              선택        선택

### 조리

1.  우삼겹을 중불에서 볶아 기름을 낸다.
2.  양파와 다진 마늘을 넣는다.
3.  약불로 낮추고 고춧가루를 20\~30초 볶는다.
4.  진간장을 가장자리에 넣어 약 10초 끓인 후 섞는다.
5.  물, 코인육수, 멸치액젓, 애호박을 넣는다.
6.  끓기 시작하면 중불에서 3\~4분 끓인다.
7.  순두부를 큼직하게 넣고 약 3분 더 끓인다.
8.  후추와 선택 재료를 넣는다.

**핵심:** 별도 식용유 대신 우삼겹 기름을 사용한다. 기름이 지나치게
많으면 일부 덜어낸다.

# 3. 테스트 중 레시피

> 아래 레시피는 승준이 실제로 먹어본 뒤 수정하기 위한 **초기 테스트
> 배합**이다.

## 애호박 감자 스팸 고추장찌개

**상태: 테스트 중**

  재료             1인분    2인분
  ----------- ---------- --------
  스팸               80g     160g
  감자              100g     200g
  애호박             80g     160g
  양파               50g     100g
  다진 마늘           8g      16g
  물               350ml    650ml
  고추장              1T       2T
  고춧가루          0.5T       1T
  진간장              1t       2t
  코인육수      0.5\~1개      1개
  대파            적당량   적당량

### 조리

1.  냄비에 물, 코인육수, 감자를 넣고 먼저 4\~5분 끓인다.
2.  고추장을 풀고 양파, 애호박, 마늘을 넣는다.
3.  스팸과 고춧가루를 넣고 감자가 익을 때까지 끓인다.
4.  진간장으로 마지막 간을 맞추고 대파를 넣는다.

**테스트 포인트:** 스팸과 코인육수 모두 짜므로 첫 테스트에서는 추가
소금을 넣지 않는다.

### 조리

3.  감자와 양파를 넣고 끓인다.
4.  끓으면 중불로 줄여 닭과 감자가 익을 때까지 졸인다.
5.  마지막에 대파를 넣는다.

**테스트 포인트:** 국물 농도와 단맛을 우선 확인한다.
